# Kanishka Kopperla — Portfolio Website

**Live Site:** https://kanishka-msd.github.io  
**GitHub Repo:** https://github.com/Kanishka-Msd/kanishka-msd.github.io

## About

A personal portfolio website showcasing my experience as an AI/ML Engineer, built with HTML, CSS, and vanilla JavaScript.

## Features

- Dark Netflix-inspired aesthetic with red accent colors
- Typewriter role animation cycling through 5 job titles
- Two-column hero layout with sidebar containing profile photo and links
- Scroll-reveal animations on all cards using IntersectionObserver
- Education accordion — click to expand and show courses
- Contact form with real-time JavaScript validation
- Fully responsive design for mobile and desktop
- Accessible markup — scores 10/10 on WAVE AIM accessibility audit

## Tech Stack

- **HTML5** — semantic, accessible markup
- **CSS3** — custom properties, animations, CSS Grid, Flexbox, responsive design
- **JavaScript (ES6+)** — no frameworks; IntersectionObserver, form validation, typewriter animation

## How to Run Locally

```bash
git clone https://github.com/Kanishka-Msd/kanishka-msd.github.io.git
cd kanishka-msd.github.io
open index.html
```

## How to Deploy to GitHub Pages

1. Push code to your repo
2. Go to **Settings → Pages → Source**
3. Select branch `main` and click **Save**
4. Site will be live at `https://kanishka-msd.github.io`
